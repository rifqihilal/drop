AI agent

Agent bekerja, kamu tetap tahu.

Progres Claude Code, OpenCode, Gemini, Codex, Cursor, Hermes, OpenClaw, GLM, dan DeepSeek tampil di notch, masing-masing dengan warna dan tandanya sendiri. Tidak perlu bolak-balik ke terminal untuk tahu agent sedang apa.

  • Langkah yang sedang jalan, lama giliran, rencana kerja, dan balasan terakhir.
  • Izinkan atau tolak perintah, dan jawab pertanyaan agent, langsung dari notch.
  • Beberapa agent sekaligus tampil sebagai satu strip, dengan daftar semua sesi.

Hubungkan sekali dari Settings → AI agent.
